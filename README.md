# Comprendo

Comprendo charts a codebase and lets you explore it. It extracts the project's
files, symbols, and relationships into a SQLite chart, annotates it with a
language model through the `/chart` tools of Claude Code and opencode, and draws
it in an interactive viewer.

See [docs/main.md](docs/main.md) for the full documentation: requirements,
quick start, extraction backends, viewer controls, the chart format, and
development notes.
